CA02 - Assign new BOM to routings (algorithm)

KEYWORD action error success # comment

CONNECT to SAP READ Excel file # CHANGE_BOM result (create_main.py) SET materialList to unique Parent Materials WHERE STATUS = SUCCESS FOR EACH material IN materialList TRY # ---- Phase 1: read the groups (CA02 visit 1, read only) GO TO CA02 ENTER material and plant, PRESS Enter IF group pop-up is shown THEN SET groupList to empty FOR EACH row IN group pop-up IF Group AND GrC are both blank THEN STOP reading END IF IF Group is filled THEN ADD new group to groupList, REMEMBER its row number END IF ADD GrC to the last group in groupList END FOR ELSE SET groupList to one group with all GrC from the header overview END IF # ---- Phase 2: process each group (one CA02 visit per group) FOR EACH group IN groupList GO TO CA02 ENTER material and plant, PRESS Enter IF group pop-up is shown THEN DOUBLE-CLICK group's row READ all GrC rows in the header overview FOR EACH GrC IN group IF GrC is not in header overview THEN RAISE error "GrC not found" END IF DOUBLE-CLICK GrC row PRESS btn[7], DOUBLE-CLICK BOM row 8 SET selectedCount to 0 FOR EACH row IN component table IF row is blank THEN STOP scanning END IF IF operation (txt[10]) is empty THEN SELECT the row, INCREMENT selectedCount END IF END FOR IF selectedCount > 0 THEN PRESS btn[5] IF operation pop-up is not shown THEN RAISE error "btn[5] did not open popup" END IF TYPE "0020", PRESS OK, PRESS Enter END IF PRESS Back 3 times IF header overview is not shown THEN RAISE error "not back on header overview" END IF ADD "group/GrC" to doneList END FOR PRESS Save END FOR SET status to SUCCESS CATCH error SET status to FAILED, message to error text END TRY WRITE status, message, doneList to Excel END FOR
